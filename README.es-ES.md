Laravel es un framework de aplicaciones web con una sintaxis expresiva y elegante. Creemos que el desarrollo debe ser una experiencia creativa y agradable para ser realmente satisfactorio. Laravel intenta eliminar los dolores de cabeza del desarrollo facilitando tareas comunes utilizadas en la mayoría de los proyectos web, como autenticación, enrutamiento, sesiones, colas y almacenamiento en caché.

Laravel es accesible, pero a la vez potente, ofreciendo las poderosas herramientas necesarias para aplicaciones grandes y robustas. Un excelente contenedor de inversión de control, un sistema de migraciones expresivo y un soporte para pruebas unitarias estrechamente integrado te brindan las herramientas que necesitas para construir cualquier aplicación que se te haya asignado.
